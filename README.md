# Simulation monorepo

This repository keeps two generations of the bankroll-management simulators:

- [`simulation-original/`](simulation-original/) — the original simulator, optimizer, GUI, and reports.
- [`simulation-current/`](simulation-current/) — the current BRM research suite with real-odds simulations, strategy comparisons, saved results, and the latest dispersion experiments.

Each project keeps its own README and dependencies. Run commands from the corresponding project directory.
