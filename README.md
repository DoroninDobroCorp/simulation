# Лаборатория банкролла

Monte Carlo симуляции банкролл-менеджмента для value-ставок: сколько ставить, чтобы банк пережил дисперсию.

> **Сколько ставить на месяц при ROI 5% и кэфах 1.5–4** — агрессивно, умеренно и консервативно для большого банка: [reports/MONTH_ROI5.md](reports/MONTH_ROI5.md), интерактивно — вкладка «Месяц» в `web/index.html`.

> **Прежние результаты этого репозитория некорректны** — в 23 из 25 стратегий «процент от банка» на деле был флэтом от начального банка, банк в части расчётов уходил в минус, рейтинги строились по среднему. Подробности и сравнение «было/стало»: [AUDIT.md](AUDIT.md). 15 из 17 найденных ошибок исправлены в коде (одна — свойство лог-формулы, одна — неравные условия в старых combat-сравнениях), актуальные цифры — в [reports/RESULTS.md](reports/RESULTS.md).

## Быстрый старт

```bash
pip install -r requirements.txt
pytest tests                  # проверка движка, ~10 секунд
python -m brm.report          # исследования -> reports/RESULTS.md, ~15–20 минут
python -m brm.month_study     # месяц при ROI 5%, кэф 1.5–4 -> reports/MONTH_ROI5.md, ~20 минут
python web/build.py           # пересобрать web/index.html из предрасчётов
```

Своя симуляция:

```python
import brm
from brm import strategies as S

pool = brm.load_real_bets()                          # 1013 реальных ставок: кэф + EV модели
market = brm.make_market(pool, roi=0.025)            # истинный средний ROI 2.5%
cfg = brm.SimConfig(n_sims=5000, n_bets=1000, cap=0.10)
res = brm.run(S.Kelly(mult=0.5), market, cfg)
print(brm.summarize(res))                            # медиана, P(минус), P(просадка ≥ 50%) …
```

Сравнение стратегий при одинаковом риске:

```python
from brm.optimize import leaderboard
rows = leaderboard(market, cfg, profile='cautious')  # P(просадка ≥ 50%) ≤ 3.5%
```

## Модель

- **Ставки.** Кэф и оценка EV берутся бутстрепом из 1013 реальных ставок (`matching_teams_clean.csv`) или из генератора по ТЗ (кэф 1.5–3.5, средний 2.8).
- **Перевес.** Истинная вероятность выигрыша `p = (1 + EV) / кэф`. Режимы: у всех ставок одинаковый EV (как в старых расчётах); EV каждой ставки из данных, отмасштабированный к заданному среднему ROI; оценка модели может быть завышена и зашумлена — стратегия ставит по оценке, а исход разыгрывается по правде.
- **Ставка.** Доля стратегии × база (живой банк или снимок раз в K ставок), не больше капа и не больше живого банка; опционально отклонение суммы, округление и минимальная ставка.
- **Честное сравнение.** Рынок и исходы идут из отдельного генератора, поэтому все стратегии с одним seed играют одни и те же ставки (common random numbers). Сравнение — при равном риске: размер каждой стратегии калибруется до лимита профиля, ранжирование по медиане.

## Главные выводы (ROI 2.5%, 1000 ставок)

- **Дисперсия важнее стратегии.** Стандартное отклонение ROI за 1000 ставок — 4.2 п.п., поэтому даже при флэт-ставке 27% серий заканчиваются в минусе, а при ставке от банка — от 26 до 45% в зависимости от стратегии и размера. Чтобы шанс минуса упал до 3%, нужно около 10 000 ставок.
- **2% от банка — это уже больше полного Келли** для средних кэфов 2.76: медиана около +16%, но просадка ≥ 50% у 71% серий.
- **Среди ставок от банка при равном риске лучше всего ставка ∝ EV / (кэф − 1)**: Келли, равная ей при одинаковом EV «постоянная прибыль» и близкая лог-формула. Это на 2–7 п.п. медианы лучше фиксированного процента в осторожном и сбалансированном профилях. Стратегии «по сериям» (анти-мартингейл, динамический %) хуже — исходы независимы.
- **На горизонте 1000 ставок флэт от начального банка не хуже ставки от банка в рискованных профилях.** В рискованном профиле он лучший по медиане в обеих моделях EV, в сбалансированном — лучший при одинаковом EV у всех ставок (при EV каждой ставки из данных Келли там на 2.6 п.п. лучше). При перевесе 2.5% компаундинг не успевает окупить волатильность; преимущество ставки от банка проявляется на длинной дистанции.
- **Жёсткий лимит просадки лучше всего держит Келли с полом** (Grossman–Zhou): при «никогда не терять 50% от пика» он лучший по медиане.
- **Ошибка модели EV опаснее выбора стратегии.** Если модель завышает EV вдвое, полный Келли по модели даёт медиану около +4% и просадку ≥ 50% в 99% серий. Лучшая медиана тогда у половины Келли по модели, но и там просадка ≥ 50% у половины серий.
