## 🎯 СУТЬ KELLY CRITERION

### Простыми словами:

**Kelly отвечает на вопрос:**  
*"Какой % от банка ставить, чтобы МАКСИМИЗИРОВАТЬ рост капитала в долгосрочной перспективе?"*

### Идея:

```
Если у тебя есть МАТЕМАТИЧЕСКОЕ ПРЕИМУЩЕСТВО (edge),
Kelly рассчитывает ОПТИМАЛЬНЫЙ размер ставки:

- Не слишком маленький (теряешь потенциал)
- Не слишком большой (рискуешь всем)
- РОВНО ТОТ, который максимизирует логарифмический рост
```

---

## 📐 МАТЕМАТИКА (упрощенно)

### Формула Kelly:

```
f = (b × p - q) / b

где:
f = доля банка для ставки (Kelly fraction)
b = odds - 1 (выигрыш на 1 единицу)
p = вероятность ВЫИГРЫША
q = вероятность ПРОИГРЫША = 1 - p
```

### Пример 1: Монетка с преимуществом

```
Игра: Монетка

Условия:
- Коэффициент 2.0 (если WIN → удвоение)
- Вероятность WIN = 55% (у тебя edge!)

Расчет:
b = 2.0 - 1 = 1.0
p = 0.55
q = 0.45

Kelly = (1.0 × 0.55 - 0.45) / 1.0
      = (0.55 - 0.45) / 1.0
      = 0.10 / 1.0
      = 0.10 = 10%

Ответ: Ставь 10% от банка!
```

### Пример 2: Беттинг с ROI=7%

```
Условия:
- Средний коэффициент = 2.76
- Твой ROI = 7% (edge!)

Шаг 1: Найти реальную вероятность
ROI = p × (odds - 1) - (1 - p)
0.07 = p × 1.76 - (1 - p)
0.07 = p × 1.76 - 1 + p
1.07 = p × 2.76
p = 1.07 / 2.76 = 0.388 (38.8%)

Шаг 2: Kelly
b = 2.76 - 1 = 1.76
p = 0.388
q = 0.612

Kelly = (1.76 × 0.388 - 0.612) / 1.76
      = (0.683 - 0.612) / 1.76
      = 0.071 / 1.76
      = 0.040 = 4%

Ответ: Полный Kelly = 4% от банка
```

## 🎮 FRACTIONAL KELLY (почему 0.25, 0.50, 1.5?)

### Полный Kelly (f = 1.0) - агрессивный

```
Kelly говорит: "Ставь 4%"
→ Ты ставишь 4% (полный Kelly)

Результат: Максимальный рост, но большие просадки
```

### Четверть Kelly (f = 0.25) - консервативный

```
Kelly говорит: "Ставь 4%"
→ Ты ставишь 4% × 0.25 = 1%

Результат: Медленнее рост, но ГОРАЗДО меньше просадки
```

### Полтора Kelly (f = 1.5) - агрессивный

```
Kelly говорит: "Ставь 4%"
→ Ты ставишь 4% × 1.5 = 6%

Результат: Быстрее рост, но больше риск
```

## 💡 ПОЧЕМУ KELLY РАБОТАЕТ ЛУЧШЕ ДРУГИХ?

### 1. **Математически оптимален**

```
Kelly = единственная стратегия, которая:
- Максимизирует логарифмический рост
- Никогда не приводит к банкротству (при правильном расчете)
- Автоматически учитывает edge и риск
```

### 2. **Адаптируется к коэффициентам**

```python
# Высокий коэффициент (3.5)
win_prob = 1.07 / 3.5 = 0.306
Kelly = меньше ставка (больше риск)

# Низкий коэффициент (1.8)
win_prob = 1.07 / 1.8 = 0.594
Kelly = больше ставка (меньше риск)
```

### 3. **Работает с любым распределением**

```
adaptive_constant_profit:
- Фиксированная целевая прибыль
- Не адаптируется к изменению edge

Kelly:
- Автоматически подстраивается
- Если edge растет → ставки растут
- Если edge падает → ставки падают
```

## 🔍 СРАВНЕНИЕ С ДРУГИМИ СТРАТЕГИЯМИ

### vs Fixed Fraction (просто 1%, 2%, 3%...)

```
Fixed Fraction:
"Всегда ставлю 2% от банка"

Проблема:
- Не учитывает коэффициент
- Не учитывает edge
- Одинаковая ставка на odds=1.5 и odds=5.0

Kelly:
- На odds=1.5 ставка БОЛЬШЕ (меньше риск)
- На odds=5.0 ставка МЕНЬШЕ (больше риск)
- Оптимально!
```

### vs adaptive_constant_profit

```
adaptive_constant_profit:
"Хочу заработать X% с каждой ставки"
→ Ставка = target / (odds - 1)

Проблема:
- Фиксированная цель не оптимальна
- Не учитывает реальную вероятность
- Параметр k нужно подбирать вручную

Kelly:
- Автоматически находит оптимум
- Учитывает реальную вероятность из ROI
- Математически доказано оптимален
```

### vs Martingale/Anti-Martingale

```
Anti-Martingale:
"После WIN увеличиваю ставку × 1.3"

Проблема:
- Зависит от паттернов (серии)
- Может дать огромные ставки после серии
- Не оптимален математически

Kelly:
- Работает на КАЖДОЙ ставке независимо
- Размер зависит только от edge и odds
- Не зависит от истории
```

## 🎯 ПРАКТИЧЕСКИЙ ПРИМЕР

### Ситуация:

```
У тебя: 10,000 €
Твой ROI: 7%
Средний коэффициент: 2.76

Вопрос: Сколько ставить?
```

### Вариант 1: Fixed 2%

```python
bet = 10,000 × 0.02 = 200 €

Всегда 200 € (пока банк 10k)

Результат через 1,000 ставок:
Profit: ~+650%
Банк: ~75,000 €
```

### Вариант 2: Kelly 1.0 (полный)

```python
# Для odds = 2.76
win_prob = 1.07 / 2.76 = 0.388
kelly = (1.76 × 0.388 - 0.612) / 1.76 = 0.04
bet = 10,000 × 0.04 = 400 €

# После каждого пересчета банка:
# Банк 12,000 → bet = 480 €
# Банк 15,000 → bet = 600 €
# и т.д.

Результат через 1,000 ставок:
Profit: ~+977%
Банк: ~107,700 €
```

### Вариант 3: Kelly 0.5 (половина)

```python
kelly = 0.04 × 0.5 = 0.02
bet = 10,000 × 0.02 = 200 €

(как Fixed 2%, но адаптируется к odds!)

Результат через 1,000 ставок:
Profit: ~+257%
Банк: ~35,700 €
Worst DD: только -88% (vs -99.4% у полного)
```

**Kelly 0.5 дает в 2.5 раза больше чем Fixed!**

## 📚 ИСТОРИЯ KELLY CRITERION

### Кто придумал?

**John Larry Kelly Jr.** (1956 год)  
Работал в Bell Labs, изучал теорию информации

### Оригинальная задача:

```
"У тебя есть инсайдерская информация
о результате скачек.

Сколько ставить, чтобы максимизировать рост капитала?"
```

### Теорема Kelly:

```
"Ставка = f, где f максимизирует:
E[log(1 + f × X)]

где X = результат ставки (±)
```

### Применение:

- 🎰 Казино (блэкджек, покер)
- 📈 Трейдинг (Уоррен Баффет использует!)
- 🎯 Беттинг (спортивные ставки)
- 💼 Инвестиции (венчурный капитал)

## ⚠️ КРИТИЧЕСКИ ВАЖНО!

### 1. **Kelly требует ТОЧНОЙ вероятности**

```
❌ НЕПРАВИЛЬНО:
win_prob = 1 / odds  # Букмекерская оценка
→ Kelly = 0% (нет edge!)

✅ ПРАВИЛЬНО:
win_prob = (ROI + 1) / odds  # Реальная вероятность
→ Kelly > 0% (есть edge!)
```

### 2. **Fractional Kelly = страховка от ошибок**

```
Если твоя оценка вероятности неточна:

Полный Kelly (1.0):
→ Может дать огромные просадки

Четверть Kelly (0.25):
→ Защищает от ошибок оценки
→ Меньше просадки
→ Всё ещё хороший рост
```

### 3. **Kelly НЕ защищает от банкротства при >100%**

```
Kelly 2.0 (двойной):
→ Ставки слишком большие
→ Можно обанкротиться!

Наши результаты:
- Kelly 1.5: 0% банкротств
- Kelly 2.0: 0.09% банкротств
- Kelly 2.5: 0.56% банкротств
- Kelly 3.0: 2.31% банкротств
```
