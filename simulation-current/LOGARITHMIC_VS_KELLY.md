## ⚖️ ПЛЮСЫ И МИНУСЫ

### Logarithmic формула:

**ПЛЮСЫ:**
✅ Проще настраивать (один параметр `defaultRisk`)  
✅ Интуитивно понятна (больше риск → агрессивнее)  
✅ Работает хорошо в консервативной зоне  
✅ Побеждает Kelly в некоторых категориях  
✅ Защита через `maxBetPercent=5%`  

**МИНУСЫ:**
❌ Чуть менее эффективна в среднем (-9.1%)  
❌ Меньше гибкости  
❌ Не математически оптимальна  
❌ Логарифм усложняет интерпретацию  

---

### Kelly Criterion:

**ПЛЮСЫ:**
✅ Математически оптимальна (доказано!)  
✅ Максимизирует логарифмический рост  
✅ На 9.1% эффективнее в среднем  
✅ Больше гибкости (fraction 0.1-2.0)  
✅ Проще понять: fraction = доля Kelly  
✅ Широко используется профессионалами  

**МИНУСЫ:**
❌ Нужно понимать концепцию fraction  
❌ Требует корректного расчета вероятности

## 🔧 КАК ПЕРЕЙТИ С LOGARITHMIC НА KELLY?

### Формула перевода:

```python
kelly_fraction = 0.7 / sqrt(defaultRisk)

# Примеры:
defaultRisk = 25 → kelly_fraction ≈ 0.14
defaultRisk = 20 → kelly_fraction ≈ 0.16
defaultRisk = 15 → kelly_fraction ≈ 0.18
defaultRisk = 12 → kelly_fraction ≈ 0.20
defaultRisk = 10 → kelly_fraction ≈ 0.22
```

### Код замены:

```python
# Было (Logarithmic):
edge = min(ROI * 100, 8.0)
edge_decimal = edge / 100
log_factor = 1 - (1 + edge_decimal) / odds
bet_pct = log10(log_factor) / log10(10^-defaultRisk)

# Стало (Kelly):
win_prob = (1 + ROI) / odds
kelly = (b × win_prob - (1 - win_prob)) / b
bet_pct = kelly × fraction
```
