# 📊 Kelly vs Logarithmic - Сводная таблица CSV

## 📄 Файл: `kelly_vs_logarithmic_all_32_variants.csv`

### Что в файле:

**32 варианта BRM стратегий** (отсортировано по прибыльности):
- **20 Kelly Criterion** (fraction 0.10-3.00)
- **12 Logarithmic** (risk 3-25)

### 🎯 Как использовать:

#### 1. Открыть в Excel/Google Sheets:
```
Двойной клик на файле → откроется в Excel
или
Загрузить в Google Sheets для онлайн работы
```

#### 2. Полезные операции:

**Сортировка:**
- По прибыли (Profit_%)
- По риску банкротства (Bankrupt_%)
- По просадке (Worst_DD_%)

**Фильтрация:**
- Только Kelly: Method = "Kelly"
- Только Logarithmic: Method = "Logarithmic"
- Только безопасные: Bankrupt_% = 0
- Только консервативные: DD>50_% < 10%

**Графики:**
- Profit vs Risk (Bankrupt_%)
- Profit vs Worst_DD
- Kelly vs Logarithmic comparison

#### 3. Найти вариант для своего банка:

**Пример 1: У меня 100,000 €, хочу 0% сливов**
```
Фильтр: Bankrupt_% = 0
Поиск: "100k" в Recommended_Bank
Результат: 
  - Rank #27: Kelly 0.25 → +91%
  - Rank #28: Logarithmic 20 → +90%
```

**Пример 2: У меня 10,000 €, готов к просадкам, но 0% сливов**
```
Фильтр: Bankrupt_% = 0
Поиск: "10k" в Recommended_Bank
Сортировка: по Profit_% (убывание)
Результат:
  - Rank #9: Logarithmic 5 → +1,027%
  - Rank #10: Kelly 1.00 → +977%
```

**Пример 3: У меня 5,000 €, хочу максимум с 0% сливов**
```
Фильтр: Bankrupt_% = 0
Поиск: "5k" в Recommended_Bank
Сортировка: по Profit_% (убывание)
Результат:
  - Rank #6: Kelly 1.50 → +2,244% 👑
  - Rank #7: Logarithmic 4 → +1,725% 💎
```

### 📊 Колонки в CSV:

| Колонка | Описание | Пример |
|---------|----------|--------|
| **Rank** | Место по прибыльности (1 = лучший) | 1, 2, 3... |

### 📈 Статистика:

**Kelly (20 вариантов):**
- Средняя прибыль: +1,176%
- Средняя эффективность: 12.031
- Диапазон: от +30% (0.10) до +4,610% (3.00)

**Logarithmic (12 вариантов):**
- Средняя прибыль: +693%
- Средняя эффективность: 7.214
- Диапазон: от +67% (risk=25) до +3,166% (risk=3)

**Разница:**
- Kelly на ~70% прибыльнее в среднем
- НО: в отдельных зонах Logarithmic конкурентна!
- Например: Log 5 (+1,027%) > Kelly 1.00 (+977%)
