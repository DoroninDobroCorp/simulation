## 🏆 ДЛЯ БОЛЬШИХ БАНКОВ (50,000-100,000+ €) - KELLY CRITERION

### 🥇 #1 - KELLY 0.25 (ЛУЧШИЙ WORST DD!)

**Стратегия:** Kelly Criterion (ПРАВИЛЬНЫЙ!)  
**Параметры:** fraction=0.25

```python
from kelly_correct import kelly_correct_realistic

TARGET_ROI = 0.07  # 7%
kelly_fraction = 0.25  # Четверть Kelly

# Автоматический расчет вероятности:
win_prob = (TARGET_ROI + 1.0) / odds  # НЕ 1/odds!

# Kelly formula:
kelly_f = (b × p - q) / b, где b = odds-1
bet% = kelly_f × 0.25 × 100

# Пример: odds=2.76
# win_prob = 1.07 / 2.76 = 38.8%
# kelly_f = (1.76 × 0.388 - 0.612) / 1.76 = 3.98%
# bet = 3.98% × 0.25 = 1.0% от банка
```

**Результаты:**
- 💰 **Profit:** +91% (+91,000 € на 100k!)
- ✅ **Bankrupt:** 0.00% (НИ ОДНОГО из 10,000!)
- ✅ **DD>50%:** 0.5% (почти никогда!)
- ✅ **DD>80%:** 0.0% (никогда!)
- 🏆 **Worst DD:** -62.7% ← **ЛУЧШИЙ из всех стратегий!**

**Для кого:**
- Банк 50,000-100,000+ €
- Лучшее соотношение прибыль/риск
- Лучший Worst DD среди всех стратегий
- Даже в худшем случае банк до 37,300 € (из 100k)

**Почему Kelly ЛУЧШЕ adaptive:**
```
Adaptive k=0.20:  +47%,  worst DD -45%
Kelly 0.25:       +91%,  worst DD -63%

Kelly дает в 2 РАЗА больше прибыли!
При этом worst DD всего на 18% хуже.

ROI на риск:
Adaptive: 47% / 45% = 1.04
Kelly:    91% / 63% = 1.44 ← на 38% эффективнее!
```

**Логика Kelly:**
```
1. Рассчитывает ПРАВИЛЬНУЮ вероятность из ROI
2. Использует формулу Kelly для оптимального %
3. fraction=0.25 = консервативный подход (четверть)
4. Математически оптимален для роста капитала

Kelly = золотой стандарт управления капиталом!
```

## ⚠️ КРИТИЧЕСКИ ВАЖНО ПОНИМАТЬ!

### ❓ Почему Kelly Criterion дает худшие результаты?

**Результаты с 0% сливов:**
- adaptive_constant_profit (k=1.70): **+1,682%**
- anti_martingale (3.5%×1.3): **+1,642%**
- sqrt_roi (base=3%): +958%
- fixed_fraction/Kelly (3%): **+650%**

**ПРОБЛЕМА:** Kelly в текущей реализации использует упрощенную формулу:
```python
win_prob = 1.0 / odds  # Букмекерская вероятность!
```

При средних odds=2.76:
- `win_prob = 1/2.76 = 36.2%`
- Реальный ROI при этом = **0%** (нет преимущества!)
- Kelly = 0% → работает как простой fixed_fraction

**ПРАВИЛЬНАЯ формула:**
```python
win_prob = (ROI + 1) / odds = 1.07 / 2.76 = 38.8%
```

**ПОЧЕМУ adaptive_constant_profit ЛУЧШЕ:**
1. ✅ Не зависит от оценки вероятности (самая частая ошибка)
2. ✅ Работает от целевой прибыли напрямую
3. ✅ Адаптируется к коэффициентам автоматически
4. ✅ Масштабируется через параметр k
5. ✅ Robust к ошибкам оценки

**Детальное объяснение:** см. файл `WHY_KELLY_FAILS.md`

### Worst DD = Просадка от ПИКА, не от начального банка!

**Пример:**
```
Начальный банк: 100,000 €
Вырос до пика: 200,000 €
Worst DD: -80%
Упал до: 200,000 × (1 - 0.80) = 40,000 €

Потеря от ПИКА: 160,000 €!
Но от начального: еще +40,000 € в плюсе
```

### Worst DD -100% НЕ значит полный слив!

```
Bankrupt: 0%
Worst DD: -100%

Это значит:
- Банк может упасть до ~0.5-50 € (почти ноль)
- Но технически НЕ слив (остается копейка)
- Психологически = катастрофа
- Технически = можно продолжать

НО если банк < 1$ → это bankrupt!
```
