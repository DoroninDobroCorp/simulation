# Симуляции BRM стратегий

## Описание проекта

Симуляции для тестирования банкролл-менеджмента с реальными коэффициентами:

- **Файлы**: `generate_real_odds_simulations.py`, `run_strategies_real_odds.py`
- **Коэффициенты**: Реальные из `matching_teams_clean.csv` (1013 ставок, avg 2.76)
- **Исходы**: Случайные с индивидуальным win_rate для каждого коэффициента (общий ROI ~7%)
- **Количество**: 10,000 симуляций × 1,013 ставок
- **Размер ставок**: 
  - Без вариации: точно по формуле
  - С вариацией: случайно от 30% до 115% (шаг 5%) от расчетного

## Быстрый старт

### 1. Генерация симуляций с реальными коэффициентами
```bash
python3 generate_real_odds_simulations.py
```
Создает файл `bet_outcomes_real_odds.npz` с результатами.

### 2. Прогон всех стратегий
```bash
python3 test_all_strategies_real_odds.py
```
Тестирует все стратегии (1%, 1.5%, 2%, 5%) с и без вариации.
Результаты сохраняются в `results.csv`.

### 3. Сравнение результатов
```bash
python3 compare_with_without_variation.py
```
Показывает детальное сравнение метрик с вариацией и без.

## Структура результатов

### results.csv
Колонки:
- `strategy` - название стратегии (dynamic_percentage_X%)
- `with_variation` - применялась ли вариация размера ставок (Yes/No)
- `avg_bet_%` - средний размер ставки от текущего банка
- `roi_%` - ROI с оборота
- `avg_profit_%` - средняя прибыль за симуляцию
- `bankrupt_%` - процент сливов
- `dd>20_%`, `dd>50_%`, `dd>80_%` - процент просадок от пика
- `avg_maxdd_%` - средняя максимальная просадка
- `description` - описание правил стратегии

## Ключевые выводы

### Влияние вариации размера ставок (30%-115%)

**Bet size 1.5%:**
- Сливов: 0.21% → 0.03% (-85% 📉)
- DD > 50%: 8.77% → 4.12% (-53% 📉)
- Прибыль: 106.41% → 77.07% (-28% 📉)

**Bet size 5.0%:**
- Сливов: 16.03% → 10.92% (-32% 📉)
- DD > 50%: 60.77% → 51.50% (-15% 📉)
- Прибыль: 354.70% → 256.92% (-28% 📉)

### Общие выводы:
1. ✅ ROI с оборота остается ~7% в обоих случаях
2. ✅ Вариация СНИЖАЕТ риски (меньше DD, меньше сливов)
3. ⚠️ Вариация СНИЖАЕТ среднюю прибыль на ~20-30%
4. 📊 Эффект вариации сильнее при больших bet_size

## Добавление новой стратегии
```python
from generate_real_odds_simulations import load_real_odds_outcomes
from run_strategies_real_odds import run_strategy_with_real_odds, save_results_to_csv

outcomes, odds = load_real_odds_outcomes()

# Без вариации
result = run_strategy_with_real_odds('dynamic_percentage', outcomes, odds, 1.5, apply_variation=False)
save_results_to_csv(result)

# С вариацией
result = run_strategy_with_real_odds('dynamic_percentage', outcomes, odds, 1.5, apply_variation=True)
save_results_to_csv(result)
```

## Метрики

- **ROI%** - возврат с оборота (целевой 7%)
- **Avg Profit%** - средняя прибыль от начального банка
- **Bankrupt%** - процент симуляций с банкротством
- **DD>X%** - процент симуляций с просадкой >X% **от пика**
- **Avg MaxDD%** - средняя максимальная просадка от пика

## Параметры вариации

Размер реальной ставки = расчетная ставка × случайный_коэф

Где случайный_коэф ∈ [0.30, 0.35, 0.40, ..., 1.10, 1.15]

Это имитирует реальность: не всегда получается поставить точную сумму.
